# Leadership Academy

A 60-day, interactive leadership course for work **and** home, taught daily by Claude.
It draws on books like *7 Habits*, *Extreme Ownership*, *Radical Candor*, *Crucial Conversations*, *Multipliers* and *Good to Great*, and on leaders from Marcus Aurelius and Lincoln to Mandela and Bill Campbell.

## How to use

Open a Claude Code session on this repo and type **`/lesson`** (or just "teach me today's lesson").

Other things you can say:
- `quick lesson`: a 5-minute version
- `I have a situation…`: live coaching on a real problem
- `quiz me`: a review across the lessons you've completed
- `role-play <scenario>`: practice a hard conversation

Each session takes about 15 minutes: check-in on yesterday's challenge → quick recall → story → idea → work scenario → home scenario → quiz → today's challenge. Your progress and journal are saved in `progress/` and `journal/` and pushed to the repo.

See `curriculum/00-overview.md` for the full 60-day map.
